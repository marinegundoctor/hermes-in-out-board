# In-Out Board Roadmap

## UI/UX Revamp
- [ ] **Touch Screen Interface Redesign**: Redesign the touchscreen interface to increase flow and reduce clutter. Consider moving away from the dense list view to a grid of large square icons or tiles for personnel. Tapping a person's tile would open their context menu for checking in/out. This will make the touch experience much faster and more user-friendly for physical interactions.
